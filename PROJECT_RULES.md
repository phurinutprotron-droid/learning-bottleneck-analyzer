# Project rules

- Keep all project files and tool caches in this workspace.
- Never commit secrets, local databases, real student records, or tokens.
- Preserve original answers and assessment/item/graph versions.
- Every diagnostic inference must reference observed response evidence.
- Confidence alone never establishes a misconception.
- Graph adjacency, descriptive gains, and correlations are not causal evidence.
- AI suggestions are advisory; validated deterministic rules decide diagnostics.
- Mark sample content unvalidated and synthetic data as software testing only.
- Enforce role and ownership checks on every student record endpoint.
- Run meaningful tests after major modules; record actual results in BUILD_STATUS.md.
- Do not claim research results or expert approval without real evidence.
