# 21-day development plan

This is the requested sequencing and pilot preparation roadmap, not a claim that 21 calendar days have elapsed.

| Days | Work | Exit checks |
| --- | --- | --- |
| 1–3 | Modular monolith, configuration, SQLAlchemy models, Alembic, authentication and consent | Migration on empty SQLite, role and ownership API tests |
| 4–7 | Versioned assessments, immutable responses, rubric evidence and competing hypotheses | Ten diagnostic scenarios and end-to-end API tests |
| 8–10 | Provenance-bearing graph, validation, dependency traversal, heuristic priority | Cycle and graph tests; explain score components |
| 11–13 | Discriminating verification selection and support updates | Contradictory verification and repeat protection tests |
| 14–16 | Optional Gemini provider; React student/teacher/research views | AI validation tests, frontend component and build checks |
| 17–19 | Intervention, parallel retest, descriptive outcomes, exports and research protocol | Integrated assessment → verification → intervention → retest |
| 20–21 | Regression, accessibility review, deployment docs, pilot readiness | Full checks, explicit limitations and remaining work |

Prioritize complete vertical flows. Sample packs require qualified content review, cognitive interviews, item analysis, and prospective evaluation before a research pilot. Never substitute software tests for educational validation.
